# 🐾 양구오시개 (양구군 반려동물 관광 안내 가이드)

양구군을 방문하는 반려가족들을 위한 모바일 및 PC 반응형 지도 중심의 반려동물 동반 관광 안내 웹페이지입니다. '댕댕맵(dangdangmap.net/pet)' 스타일의 직관적인 지도 UI와 경주시 '경주오시개' 서비스를 벤치마킹한 카테고리 구성으로 제작되었습니다.

---

## 🌟 주요 특징 및 기술 스펙

### 1. 웹 프레임워크 & CSS 프레임워크 배제
- 오직 순수 **HTML5**, **CSS3**, **바닐라 자바스크립트(Vanilla JS)** 규격으로만 개발되어 가볍고 유지보수가 쉽습니다.
- 의존성 라이브러리가 없어 무거운 빌드 과정 없이 `index.html` 파일을 더블클릭하거나 경량 웹 서버로 즉시 구동할 수 있습니다.

### 2. UI/UX 레이아웃 (댕댕맵 스타일)
- **데스크톱 (PC)**: 30% 폭의 좌측 검색/필터 사이드바와 70% 폭의 우측 지도 분할 배치.
- **모바일 (반응형)**: 목록과 지도가 겹치는 배치로, 하단의 **'목록 보기' / '지도 보기'** 플로팅 버튼을 통해 화면을 부드럽게 토글할 수 있습니다.
- **상세 패널 (Slide-in / Bottom Sheet)**: 장소 클릭 시 PC에서는 우측에서 슬라이드인 되고, 모바일에서는 아래에서 위로 올라오는 바텀시트 서랍 형태로 구현되어 있습니다.

### 3. 주요 기능 및 필터링
- **통합 검색**: 실시간으로 장소명, 주소, 태그 및 설명글의 매칭을 수행합니다.
- **카테고리 퀵 필터**: '전체', '숙소', '식당/카페', '관광지', '의료/편의' 탭 필터링.
- **반려견 동반 조건 세부 필터**: 소형견/중형견/대형견 동반 가능 여부 및 목줄 프리(오프리쉬) 구역 유무를 칩(Chip) 형태로 제어합니다.
- **댕댕 가이드**: 햄버거 메뉴를 누르면 양구군 맞춤형 여행 코스(당일치기/1박2일) 및 공공장소 펫티켓 가이드 모달을 제공합니다.

## ⚙️ 로컬 구동 및 테스트 방법

본 웹앱은 별도의 빌드 단계가 없으므로 아래 방법 중 하나를 선택해 즉시 테스트할 수 있습니다.

### 방법 1. index.html 직접 열기
- 작업 폴더 내 `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저에 더블클릭하여 엽니다.

### 방법 2. 간단한 로컬 웹 서버 구동 (권장)
지도의 모바일 최적화 레이아웃 invalidate 사이즈 검증 및 카카오맵 전환 테스트를 원활하게 진행하려면 로컬 웹 서버로 여는 것이 좋습니다.
- **VS Code Extension**: `Live Server` 플러그인을 설치 후 하단의 `Go Live` 클릭.
- **Node.js (npx)**:
  ```bash
  npx serve .
  ```
- **Python**:
  ```bash
  python -m http.server 8000
  ```

## 🗺️ 지도 API 확장 가이드 (카카오맵 전환)

이 프로젝트는 API 키 등록 절차 및 로컬 인증 지연 오류를 예방하고자 **OpenStreetMap(Leaflet.js)** 엔진을 기본값으로 탑재하고 있습니다. 이를 상용 **Kakao Maps API**로 전환하고자 할 경우 아래 절차를 따르십시오.

### 단계 1: 카카오맵 API Key 발급
1. [Kakao Developers](https://developers.kakao.com/)에 접속하여 가입 후 새 애플리케이션을 생성합니다.
2. [플랫폼 설정] 탭에서 **웹(Web)**을 선택한 뒤, 로컬 테스트용 도메인(예: `http://localhost:5500` 또는 `http://127.0.0.1:8000` 등 구동 중인 로컬 주소)을 등록합니다.
3. 앱 키 메뉴에서 **JavaScript 키**를 복사합니다.

### 단계 2: 웹페이지에서 적용
1. 웹페이지 우측 상단의 햄버거 바(`☰`) 버튼을 클릭합니다.
2. **[지도 설정]** 탭으로 이동합니다.
3. 발급받은 **JavaScript API Key**를 입력한 후 **[적용하기]**를 누르면, 지도 엔진이 Kakao Maps로 즉각 스위칭되어 렌더링을 시도합니다.
4. 입력한 API Key는 웹 브라우저의 `localStorage`에 자동 보관되어, 재부팅/새로고침을 하더라도 설정이 유지됩니다.
5. 만약 소스코드 레벨에서 처음부터 카카오맵을 로드하고 싶다면 `index.html`에 카카오맵 스크립트를 삽입하고 `app.js`의 `state.mapEngine` 기본값을 `'kakao'`로 초기 설정하시면 됩니다.
